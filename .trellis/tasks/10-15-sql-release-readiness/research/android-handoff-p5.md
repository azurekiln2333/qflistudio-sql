registrant in release mode. Flutter's `injectPlugins(releaseMode: true)` filters
out `dev_dependency` plugins, so the registrant now correctly contains only
`file_selector_android` (FileSelectorAndroidPlugin) and `path_provider_android`
(PathProviderPlugin) — **no `integration_test`**.
